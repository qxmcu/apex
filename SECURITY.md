# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The ApexCompress team takes security seriously. ApexCompress uses cryptographic encryption (PBKDF2-HMAC-SHA256, AES-256-CTR, HMAC-SHA256 Encrypt-then-MAC) to protect sensitive archives.

If you discover a security vulnerability or cryptographic weakness, please do NOT create a public issue. Instead, report it privately to the maintainers at:

**security@apexcompress.org** (or via GitHub Private Vulnerability Reporting).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Affected versions and environments.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch.
